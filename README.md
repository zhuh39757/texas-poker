# 德州扑克 · 朋友联机版

在浏览器里和朋友联机打德州扑克（无限注 No-Limit Hold'em）。**只计积分，不涉及真钱。**

电脑和手机都能玩，不用装 App；可以在自己电脑上开局，同一个 WiFi 下的朋友直接加入，也可以部署到云服务器远程联机。

## 功能

| 类别 | 内容 |
|---|---|
| 牌局 | 单桌 2–9 人，其他人可以观战；主池/边池自动计算；房主点"开局"后才发牌 |
| 积分 | 坐下时借入起始筹码，之后随时可以再借；**净盈亏 = 当前筹码 − 累计借入** |
| 计分板 | 本场排名 + 历史总榜 + 过往场次记录 |
| 进门 | 只输昵称；放到公网时整个房间共用一个进门口令 |
| 社交 | 聊天（快捷短语和表情）、座位气泡、文字版手牌历史 |
| 外观 | 12 个可选角色、筹码堆、发牌/翻牌/筹码飞行等动画，界面适配手机 |
| 声音 | 浏览器原创合成的背景音乐和音效，也可以换成自己有权使用的音频 |
| 操作 | 电脑快捷键：F 弃牌 · C 或空格 过牌/跟注 · R 加注 · 回车 确认加注 |

## 快速开始

需要 [Node.js](https://nodejs.org/) 20 或更高版本。

```bash
npm install
npm start
```

启动后窗口会打印本机的局域网地址（例如 `http://192.168.1.23:3000`），同一个 WiFi 下的朋友用浏览器打开这个地址就能加入。Windows 上也可以直接双击 `start-server.bat`。

常用参数：

```bash
node server/index.js --port 3000 --password 房间口令 --data data/db.json
```

> 项目里的 `.npmrc` 把 npm 源设成了国内镜像（npmmirror）。在国外安装慢的话，删掉这个文件即可。

## 测试

```bash
npm test                 # 37 个测试：牌型评估、分池、下注规则、随机对局压力测试、房间集成测试
npm run bots -- 3        # 让 3 个机器人坐上牌桌，一个人也能测多人局
```

想测试又不弄脏正式计分，可以单独开一个测试服务器：`node server/index.js --port 3001 --data data/test-db.json`。

## 部署到云服务器

见 [DEPLOY.md](DEPLOY.md)。提供两种安装脚本：

- `deploy/setup-user.sh`：**不需要 sudo**，适合借用别人服务器上的一个普通账号（已在真实服务器上验证）
- `deploy/setup.sh`：有 root 权限时使用

两个脚本都不碰服务器上原有的东西，程序自带一份 Node.js，以低权限用户运行。

## 技术栈

Node.js + Express + Socket.IO，前端是原生 HTML/CSS/JavaScript，计分数据存在 JSON 文件里。
